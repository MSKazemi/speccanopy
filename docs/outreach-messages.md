# Outreach messages — drafts, not sent

## Public reviewer invitation

> We're looking for experienced software architects and staff/principal engineers who can independently critique competing architectural designs in an open-source research project, Speccanopy. The first pilot uses a **public synthetic** e-commerce case. Reviewers assess boundaries, contracts, data consistency, security and reliability, with evidence-based findings; either option may be rejected. This is **not** product certification or a genuine blind benchmark. Participation is voluntary and any use of anonymized review outcomes requires explicit consent. Please register interest via https://github.com/MSKazemi/speccanopy/issues/3 (public, non-sensitive details only).
